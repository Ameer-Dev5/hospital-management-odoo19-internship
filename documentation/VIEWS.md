# Hospital Appointment Views

## List View
Used for detailed record listing and quick searching.

## Kanban View
Used for a quick workflow overview of appointments grouped by status.

## Calendar View
Used for scheduling and viewing appointments by date and time.

## Activity View
Used for managing appointment-related follow-ups and scheduled activities.

## Graph View
Used for visual analysis such as appointment counts by doctor or status.

## Pivot View
Used for multidimensional analysis such as doctor versus appointment status.

## Search and Group By
Provides filters for today's, upcoming, and completed appointments, with grouping by doctor, status, appointment type, priority, and date.
